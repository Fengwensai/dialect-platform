## 1.5 业务闭环手测（照着点一遍，预期结果在每步「预期」处）

> 顺序：后台准备 → 小程序采集 → 后台审核 → 小程序看结果。

**A. 管理后台准备**
1. 团队管理 → 新建团队码 → 选一个**未被占用**的省市（已占用：13/1301 河北石家庄、12/1201 天津；建议北京 11/1101）→ 记下团队码。
   - 预期：创建成功，列表出现该码。
2. 词条管理（或 词表导入）：确保有词条；没有则上传 Excel 或手动新建几条，省份与团队码省市一致。
3. 任务分配 → 新建任务：填名称 → 省/市选团队码对应 → **关联团队码** → 勾选 2~3 个词条 → 保存 → **发布**。
   - 预期：任务状态草稿 → 已发布。

**B. 小程序采集**
4. 首次进入弹《用户隐私保护指引》授权 → 同意。
5. 微信一键登录 → 三份协议全勾选 → 同意并继续。
   - 预期：进首页，不再被协议守卫拦截。
6. 个人信息：改昵称/头像/性别/年龄段 → 保存。把昵称改成明显违规词 → 预期「昵称包含违规内容」且不改。
7. 绑定团队：输入 A1 的团队码。
   - 预期：个人信息页显示「省 · 市」属地（只读）；再输别的码提示已绑定。
8. 录音页：只看到本地区已发布任务 → 选词条 → 开始录音（首次触发**麦克风隐私弹窗**→同意）→ 停止 → 试听 → 保存入队，录 2~3 条。
   - 预期：词条显示「已保存」。
9. 我的页：时长统计有数字。

**C. 管理后台审核 + 导出**
10. 录音审核：出现待审录音 → 试听 → 一条「通过」、一条「驳回」+备注。
    - 预期：状态流转为 已通过 / 已驳回。
11. 按任务导出 ZIP → 解压：`manifest.csv` 只含通过那条，`audios/…/` 有对应音频。

**D. 小程序看结果**
12. 回录音页刷新：通过的词条显示「已通过」，驳回的显示「需重录」+ 备注。
    - 预期：完整闭环（建团队→建任务→绑定→采集→审核→结果回写）。

**E. 两条坏路径（可选）**
13. 隐私拒绝：清理缓存重进，录音时在隐私弹窗点「拒绝」→ 友好报错、不卡死、能返回。
14. 协议升级：后台「协议管理」把「用户协议」升 v2 → 小程序被踢回登录页、只弹被改那份 → 同意后恢复。**测完降回 v1**。

**F. 领取制闭环（阶段十一）**（建议两台设备 / 两个发音人账号同时测互斥）
15. 任务分配 → 新建/编辑任务：确认「每人领取上限」可改（默认 10）。
16. 任务页：任务卡显示「总 N 条 · 已领 X 条 · 可领 Y 条」+「领取」按钮。
    - 预期：点「领取」弹选条数窗，默认取 min(可领,10)；输入超可领提示「最多可领 N 条」。
17. 领 2 条 → 词条页只看到**这 2 条**。
    - 预期：另一账号任务页该任务可领数减 2；抢领这 2 条 → 提示不可领（409）。
18. 已领 2 条录 1 条 → 进度「已录 1 / 已领 2」；未领的词条直接上传 → 403「未被你领取」（本地队列标「未领取」，不当作普通错误重试）。
19. **追加领取**：再领到上限 → 累计不超上限；达上限后再领提示「已领满」。
20. **自退**：把未录那条退回 → 确认文案「退回后释放给其他人」，另一账号可领到它。
21. **后台解绑**：任务列表「领取」弹窗 → 已录那条「解绑」禁用；未录那条解绑成功，可领数回升。
    - 预期：已录不可解绑（400），未录解绑后词条回池。

## 3. 登录流程（隐私弹窗第一触发面）

- [ ] 新用户进入登录页，点「微信一键登录」→ 正常返回 token、能进首页

- [ ] **换头像**（`chooseAvatar`）→ 触发隐私弹窗 → 同意后可选择头像
