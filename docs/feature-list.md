# 方言采集平台 · 功能清单（大白话版）

> 从零搭到上线（2026-08）的完整功能清单，按「谁在用」分三组，每条用一句话说清它是干嘛的。
> 技术细节看 `docs/api.md` / `docs/database.md` / `docs/update-workflow.md`。

一句话总览：**管理员在后台发任务，发音人用手机录方言，后台审核整理成数据集**的采集平台。

---

## 一、发音人端（微信小程序）

| 功能 | 大白话 |
|---|---|
| 微信登录 | 用微信一键进来，不用注册账号密码 |
| 三份协议勾选 | 进门前必须把《用户协议》《隐私政策》《声音授权》三份全部同意，少一份都进不来；协议更新后要重新同意 |
| 团队绑定（省+市） | 输管理员发的「团队码」即锁定所在省+市 |
| 只看本地任务 | 只能看到、只能录自己省市的任务（服务端强制，绕不过去） |
| 领任务领词条 | 挑任务里的词条来录；一个词条同一时间只给一个人录，避免重复采集 |
| 录音上传 | 念方言词条，录完自动上传；没网时先存本地排队，恢复后补传 |
| 我的进度/统计 | 看自己录了多少条、总时长多少，可导出 |
| 个人画像 + 头像 | 填性别年龄段、传头像，方便后台了解采集人群 |
| 演示任务 | 标注「演示用」的任务，供管理员自己走流程、提审期演示 |

## 二、管理后台（admin.qlzby.com）

| 功能 | 大白话 |
|---|---|
| Excel 词表导入 | 词表 Excel 直接上传解析成平台词条 |
| 任务管理 | 建/改/分配/删任务（有录音的任务会拦住不许删） |
| 团队管理 | 生成/删团队码，一码对应一个省市区 |
| 发音人管理 | 列表/筛选/编辑画像、属地纠错（自动解绑团队）、删除（有录音拦住）、两个发音人合并 |
| 词条管理 | 几千条大列表流畅滚动；新建查重；重复词条合并；启用/禁用（禁用不再对外发） |
| 词条占用 | 已选进任务/已在录的词条不让重复选入其它任务，避免撞车 |
| 录音审核 | 试听、转写、通过/驳回；驳回时勾选原因（背景噪音/念错/音量太小/普通话混读/不完整等）；批量审；键盘快捷键（空格播放/A 通过/R 驳回…）；驳回重置重录；单条误删 |
| 数据看板 | 平台/本省概览（录音量/通过率/时长）、近 7/30 天趋势、难采集词条排行、区域分布、每发音人明细、点进下钻录音与领取记录；驳回原因分布（看哪些原因最挡进度，反哺任务投放） |
| 数据导出 | 通过录音打包 ZIP + 清单；按发音人导出时长 CSV |
| 数据备份 | 定时备份数据库 + 录音文件 + 配置快照，出事故可恢复 |
| 操作审计日志 | 谁在后台做了什么都有记录，出问题可查账 |
| 登录保护 | 同 IP 短时间狂试密码会被拦，防暴力破解 |

## 三、开发 / 运维

| 功能 | 大白话 |
|---|---|
| CI 自动回归 | push 后 GitHub Actions 自动跑 16 个回归脚本 + 前端编译，红了立刻发现 |
| Deploy 一键部署 | 点按钮自动构建→同步服务器→重启→探活，替代手动命令 |
| 健康监控自愈 | 每分钟探活，服务挂了 60 秒内自动拉起 |
| 内容安全 + 上传限流 | 上传基本安全校验 + 限频，防刷爆 |
| 小程序一键上传 | 命令行传新版小程序到微信后台（miniprogram-ci），提审仍手动 |
| COS 云存储 | 接口已预留，启用后录音直接进云桶，不占服务器磁盘（当前未启用） |
