# 隐私合规整改（2026-08-29）

## 背景

微信后台发出违规通知：**违规收集用户头像昵称**，限期 2026-09-01 09:25 前整改，否则封禁「被搜索」能力。

**根因**：小程序《用户隐私保护指引》声明「头像昵称不存储于服务器，仅缓存于本地」，但代码实际把头像上传服务器（`/media/avatars/`）、昵称写入数据库，**声明与代码不符**。另有麦克风/位置信息用途写反、位置信息虚假声明（代码从未采集定位）等问题。

## 整改方案（已实施）

| 项 | 改动 | 状态 |
|---|---|---|
| 头像 | 小程序端仅本地缓存展示（`wx.saveFile`+storage），不再上传服务器；后端删除 `/api/mp/avatar` 接口、登录/资料接口不再接收存储 | ✅ 代码已改 |
| 昵称 | 保留服务器存储（后台科研识别用），指引单独声明 | ✅ 代码已改 |
| 存量清理 | `scripts/cleanup_avatars.py` 清空 `avatar_url` + 删除 `media/avatars/` 文件（昵称保留） | ✅ 脚本就绪，待生产 `--execute` |
| 隐私指引 | 见下方更新文本 | 待用户在 mp.weixin.qq.com 更新 |
| 申诉 | 见下方申诉文案 | 待用户提交 |
| 提审发布 | 重新提交小程序版本（头像本地化） | 待用户操作 |

本人小程序「语音采集助手」为方言采集与研究项目的小程序端，收到违规通知后已立即完成整改，说明如下：

1. **头像已改为仅本地缓存**：用户通过微信官方「头像昵称填写能力」（`open-type="chooseAvatar"`）选择的头像，现仅在小程序本地缓存用于展示登录状态与个人任务列表，**不再上传至服务器、不再存储**。已删除服务器上全部存量头像文件及数据。

3. **隐私指引已同步更正**：已更新《用户隐私保护指引》，将头像（仅本地缓存）、昵称（科研识别用）、麦克风（录制语音）、性别年龄段（科研统计）、团队码（地区任务分配）逐一如实声明，并删除了与实际不符的「位置信息」声明，修正了麦克风用途描述，确保**声明与代码完全一致**。
4. **采集全程合规**：头像昵称均通过微信官方「头像昵称填写能力」采集，未使用任何被禁止的接口（如 `wx.getUserInfo`、`wx.getUserProfile`）；收集前有明确的隐私授权弹窗与协议勾选确认。
